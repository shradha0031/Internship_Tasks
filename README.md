# QRCodeScanner 📷

This is an Android application built using **Jetpack Compose**, **CameraX**, and **ML Kit** that scans QR codes and automatically opens the scanned URL in a browser.

---

## 🚀 Features

- 📷 CameraX-based live preview
- 🔍 QR code detection using Google's ML Kit
- 🌐 Auto-opens scanned links in browser
- 💡 Real-time scanning with smooth UI

---

## 🛠️ Built With

- [Jetpack Compose](https://developer.android.com/jetpack/compose) – Modern UI toolkit
- [CameraX](https://developer.android.com/training/camerax) – Camera framework for Android
- [ML Kit Barcode Scanning](https://developers.google.com/ml-kit/vision/barcode-scanning) – Google’s ML library for barcode and QR scanning
- Kotlin

---

---

## 🧪 How to Run


1. Clone this repository
2. Open in Android Studio
3. Connect your Android device or emulator
4. Run the app

> Make sure the camera permission is granted when prompted.
